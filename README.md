## 🛠️ Troubleshooting Common Issues

### Problem: Application Won't Start
**Solution:** Make sure your Windows is updated. Right-click the app icon and select "Run as Administrator." If the problem continues, try reinstalling.

### Problem: Can't Add a Specific Stock
**Solution:** Check your internet connection - the app needs to fetch live market data. Try searching for the stock using its ticker symbol instead of the full company name.

### Problem: Charts Show Incorrect Values
**Solution:** Verify that you entered the correct purchase price and quantity. Go to Settings > Data and select "Refresh All Data."

### Problem: App Is Slow
**Solution:** Close other programs that use lots of memory. In Settings, reduce the number of assets displayed on the main page.

### Problem: Forgot Portfolio Password
**Solution:** Your data file is stored in a secure location. You can reset by deleting the "ghostfolio-config.json" file (back it up first!), but this will remove your current portfolio data.

## ❓ Frequently Asked Questions

### Does this work on Mac or Linux?
While the primary target is Windows, Docker users can run this on any operating system. For Mac users, try using Wine or a virtual machine.

### Do I need to pay for anything?
No! This application is completely free and open-source.

### Will my data be backed up automatically?
The app doesn't auto-backup to the cloud, but it creates a local backup file each time you close it. You can manually export your data anytime via Settings > Export.

### Can I track cryptocurrencies?
Absolutely! Bitcoin, Ethereum, and thousands of other cryptocurrencies are supported.

### Is there a mobile version?
Yes! The dashboard works as a Progressive Web App (PWA), so you can access it via your phone's browser when connected to your local network.
